# Sourcing footage

## Allowed

| Source | Licence | Credit needed |
|---|---|---|
| NASA and other US government | Public domain | No (a courtesy credit is welcome) |
| Pexels | Pexels licence | No |
| Pixabay | Pixabay content licence | No |
| Mixkit | Mixkit free licence only | No |
| Anything marked CC0 | CC0 | No |
| Anything marked CC BY | CC BY | Yes, the exact line the page gives |

## Not allowed

CC BY-SA, CC BY-NC, "editorial use only", premium or plus tiers, Mixkit clips marked "Restricted", and anything whose licence you could not read on the clip's own page.

## What goes wrong

- **Site-level assumptions.** Mixkit has free and restricted clips side by side. Coverr carries a lot of AI-generated material. Read each clip's page.
- **NASA.** Material NASA produced is public domain, but a NASA video can contain third-party music, logos or footage. Use silent crew or instrument footage, trim title and end cards, and confirm against NASA's media guidelines before a store release.
- **Spotter videos.** Many have a channel logo in a corner and title cards. A crop can remove the logo; check every frame of the window you use.
- **Livery.** An airline name on a fuselage, a shop sign, a number plate. Prefer silhouettes and night shots.
- **Resolution.** ISS night footage is often 1080x720. That is enough for a header band; it is not enough for a full-screen film.
- **Blocked downloads.** Search pages often refuse scripts while the download endpoint works. If a site fights, take another candidate. Never put a person's name, email or project name in a request.

## The sources file

Keep `docs/media/header-footage-sources.md` in the app's repo, one row per clip:

| File | Screen | Page URL | Download URL | Author | Licence (with link) | Credit required | Resolution, length | What it shows, window used |
|---|---|---|---|---|---|---|---|---|

If any clip needs credit, the app needs an acknowledgements row that shows it.
