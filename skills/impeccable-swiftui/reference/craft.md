# Craft (deprecated alias)

`craft` is a deprecated alias for an ordinary request to make new visual work. It adds no setup, interview, checkpoint, tool, or quality behavior. Apply SKILL.md's normal routing: create a missing PRODUCT.md through [init.md](init.md), then follow [new-work.md](new-work.md) for visual authority, world and screen decisions, implementation, and finish.

Do not tell users they need to invoke `craft`. Natural requests such as "build the onboarding," "make a paywall," or "redesign the settings screen" use the same flow.
